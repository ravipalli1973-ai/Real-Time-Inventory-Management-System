# 📦 Inventory Management System

A simple and user-friendly Inventory Management System built using **Python, Flask, SQLite, HTML, CSS, and JavaScript**. This application helps users manage inventory by adding, updating, searching, and deleting products through a clean web interface.

---

## 🚀 Features

- 📊 Dashboard with inventory statistics
- ➕ Add new products
- 📋 View all products
- ✏️ Edit product details
- 🗑️ Delete products
- 🔍 Search products by name, category, or supplier
- 📦 SQLite database integration
- 🎨 Responsive and clean user interface

---

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/inventory-management-system.git
```

### Navigate to the project

```bash
cd inventory-management-system
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
